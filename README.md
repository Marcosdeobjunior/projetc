# InkFlow

App desktop para escritores: projetos guardados localmente em um vault (pasta) e sincronização opcional pela nuvem do próprio usuário (Google Drive). Venda única via lojas (Microsoft Store / Mac App Store).

## Estrutura

- `app/` — o aplicativo (Tauri + React + TypeScript). Veja [`app/README.md`](app/README.md) para rodar e para o formato dos arquivos.
- `site/` — landing page estática (um único `index.html`, sem build).
